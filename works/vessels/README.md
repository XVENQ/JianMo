## 建模思路

用多条不同半径的圆形样条线作截面，沿路径方向「放样」，通过「缩放变形」曲线控制收口与鼓腹，一次得到连续变化的器皿曲面；材质用金属.jpg 做反射。

## 技术要点

- 放样后进入「变形」卷展栏，用缩放曲线精确控制轮廓
- 截面数量不必多，缩放曲线才是控制外形的主力
- 金属材质需要环境贴图才有反射细节

## 文件说明

| 文件 | 用途 |

| `vessels.max` | 主场景文件（3ds Max 2022 保存，可用 2019 及以上版本打开） |

| `preview/` | 渲染图，运行 `scripts/render_previews.ms` 生成 |

## 打开时提示贴图缺失怎么办

1. 首选：在 Max 中运行 `scripts/relink_textures.ms`，脚本会把缺失贴图重链到本目录 `textures/`；
2. 手动：`文件 → 参考 → 资源跟踪`（Shift+T），选中缺失项 → 右键「设置路径」→ 指向 `textures/`；
3. 把本目录设为 Max 项目文件夹（`文件 → 项目管理器`），贴图会按相对路径自动找到。
