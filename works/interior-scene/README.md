## 建模思路

把前面单件的家具与建筑构件组合进同一场景，按真实尺寸对齐；墙面、地面、软装分别用木纹、砖、布料贴图，通过「多维子材质」在一个对象上分区赋材质。

## 技术要点

- 统一系统单位为毫米，所有单件才能拼得上
- 多维子材质依靠「材质 ID」分区，需在面级别先指定 ID
- 贴图路径建议统一收进 textures/ 后重链

## 文件说明

| 文件 | 用途 |
|---|---|
| `interior-scene.max` | 主场景文件（3ds Max 2022 保存，可用 2019 及以上版本打开） |
| `textures/` | 该作品引用的贴图，**保持原文件名**以免重链失效 |
| `_resources.txt` | 原始的 Max 资源依赖清单（如有） |
| `preview/` | 渲染图，运行 `scripts/render_previews.ms` 生成 |

## 打开时提示贴图缺失怎么办

1. 首选：在 Max 中运行 `scripts/relink_textures.ms`，脚本会把缺失贴图重链到本目录 `textures/`；
2. 手动：`文件 → 参考 → 资源跟踪`（Shift+T），选中缺失项 → 右键「设置路径」→ 指向 `textures/`；
3. 把本目录设为 Max 项目文件夹（`文件 → 项目管理器`），贴图会按相对路径自动找到。

## 可继续改进

- 可加相机与灯光做可视化渲染
- 家具比例可再按实际产品校核
