## 建模思路

沿墙体轮廓绘制样条线，给矩形/自定义截面做「扫描」或「放样」，一次生成通长的踢脚线与顶角石膏线；遇到门洞、转角处用样条线的顶点层级单独调整。

## 技术要点

- 截面图形决定线脚造型，改截面即可换风格
- 样条线「轮廓」偏移保证线脚有厚度
- 转角处用「角点/贝塞尔」控制点类型处理硬转与弧转
- 布尔运算处理门洞断开

## 打开时提示贴图缺失怎么办

1. 首选：在 Max 中运行 `scripts/relink_textures.ms`，脚本会把缺失贴图重链到本目录 `textures/`；
2. 手动：`文件 → 参考 → 资源跟踪`（Shift+T），选中缺失项 → 右键「设置路径」→ 指向 `textures/`；
3. 把本目录设为 Max 项目文件夹（`文件 → 项目管理器`），贴图会按相对路径自动找到。

## 可继续改进

- 可加一条凹槽做「双眼皮」线脚
- 与墙面的交接处需留 1-2mm 缝隙避免 Z-fighting
