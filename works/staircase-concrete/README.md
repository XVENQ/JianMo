## 建模思路

以长方体做单级踏步，用「阵列」按高度递推复制出整跑楼梯；栏杆立柱用圆柱体阵列，扶手用样条线放样贴合坡度；踏步面用 C-A-015 地板贴图做漫反射，得到混凝土/石材观感。

## 技术要点

- 长方体参数化控制踏步 300×150×1000mm，保证比例符合建筑常识
- 阵列工具的「增量」模式沿 Z 轴递推，避免逐级手动对齐
- 圆柱阵列做栏杆立柱，间距一致，扶手用样条线 + 扫描沿坡度走
- 贴图坐标用「长方体」UVW 映射，避免拉伸

## 打开时提示贴图缺失怎么办

1. 首选：在 Max 中运行 `scripts/relink_textures.ms`，脚本会把缺失贴图重链到本目录 `textures/`；
2. 手动：`文件 → 参考 → 资源跟踪`（Shift+T），选中缺失项 → 右键「设置路径」→ 指向 `textures/`；
3. 把本目录设为 Max 项目文件夹（`文件 → 项目管理器`），贴图会按相对路径自动找到。
