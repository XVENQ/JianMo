## 建模思路

按板材逻辑建模：侧板、顶底板、层板分别用矩形挤出并给厚度，门板单独成件并留 2mm 缝；整体尺寸按 1000×350×900mm 的玄关柜常规比例控制。

## 技术要点

- 板厚统一 18mm，符合人造板规格
- 门缝用「分离面 + 缩放」而非布尔，拓扑更干净
- 层板做成可调层板（略小于内空）

## 打开时提示贴图缺失怎么办

1. 首选：在 Max 中运行 `scripts/relink_textures.ms`，脚本会把缺失贴图重链到本目录 `textures/`；
2. 手动：`文件 → 参考 → 资源跟踪`（Shift+T），选中缺失项 → 右键「设置路径」→ 指向 `textures/`；
3. 把本目录设为 Max 项目文件夹（`文件 → 项目管理器`），贴图会按相对路径自动找到。
