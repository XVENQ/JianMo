# 技法说明

把 39 件作品按**建模手法**而不是按日期重新排一遍，能看清一学期的技术路线是怎么走过来的：二维图形先立骨架，三维基本体填体积，复合对象做结构，多边形建模做有机形，材质把灰模变成能看的东西，场景把单体拼成空间。

---

## 技法一：二维样条线 → 放样 / 扫描

**核心原理**：一条路径 + 一个（或多个）截面 = 连续曲面。路径决定走向，截面决定断面形状，**缩放变形曲线**决定沿路径的变化（收口、鼓腹、扭曲）。

| 作品 | 路径/截面的做法 | 学到什么 |
|---|---|---|
| `vessels` 金属器皿组 | 多条不同半径的圆作截面，沿直线放样 | 截面数量不必多，缩放曲线才是控制外形的主力 |
| `skirting-line` 踢脚线 | 墙体轮廓作路径，矩形/线脚作截面 | 「轮廓」偏移给线脚厚度；转角靠顶点类型（角点/贝塞尔）区分硬转弧转 |
| `banana` 香蕉 | 弧线作路径 + 椭圆截面，加「弯曲」 | 有机曲线先用可编辑样条线画准，再放样 |
| `icecream-cone` 甜筒 | 星形 + 圆形截面，缩放曲线收口 | 单截面也能做出螺纹锥体 |
| `wine-glass` 酒杯 | 旋转体轮廓 + 车削 | 车削（Lathe）是回转体最快的解法 |

**踩过的坑**：截面和路径的法线方向不一致时，放样会扭转。改「放样 → 蒙皮参数 → 翻转法线」或调整截面起点可解。

## 技法二：三维基本体 + 切角 + 阵列

**核心原理**：所有复杂家具都能拆成基本体的组合；切角值决定"软"还是"硬"；阵列把"重复"变成一次参数操作。

| 作品 | 拆解方式 | 关键参数 |
|---|---|---|
| `sofa` 三人沙发 | 座箱 / 靠背 / 扶手三块切角长方体 | 切角 40–60 mm 有布艺手感 |
| `console-cabinet` 玄关柜 | 侧板、顶底板、层板分件挤出 | 板厚统一 18 mm 符合人造板规格 |
| `lounge-chair` 躺椅 | 切角体 + 圆柱腿 | 靠背倾角用旋转工具按角度捕捉 |
| `staircase-concrete` 楼梯 | 单级踏步 + 阵列递推 + 圆柱栏杆 | 阵列「增量」模式沿 Z 递推，踏步 300×150×1000 mm |
| `spiral-staircase` 旋转楼梯 | 中柱 + 单级踏步 + 旋转阵列 | 阵列总旋转量 ÷ 踏步数 = 单级递增角 |

**为什么先做基本体**：基本体自带参数，改尺寸不用动拓扑。等到必须"打破规则形状"时，才转可编辑多边形——这也是课程从项目 3 走到项目 5 的原因。

---

## 技法三：复合对象（布尔 / 图形合并 / 放样）

**核心原理**：布尔做"减法"（开孔、镂空），图形合并做"投影"（把线投到面上），放样做"扫掠"。三者都需要**操作前先把模型细分够**，否则结果会碎。

| 作品 | 运算 | 前置条件 |
|---|---|---|
| `crystal-chandelier` 水晶吊灯 | 球体与圆柱布尔差集 → 镂空环架 | 两者分段数要接近，运算后拓扑才均匀 |
| `washbasin` 台盆 | 水嘴孔布尔差集 | 开孔区域先加线细分，孔边才圆滑 |
| `logo-fruit` 水果商标 | 图形合并把矢量图标投到平板 → 挤出 | 目标面必须有足够细分，否则图标边缘锯齿 |
| `relief-text` 浮雕文字 | 文字图形合并到球面 → 挤出 | 曲面合并后要「松弛」一下避免局部穿插 |
| `wall-shelf` 墙上置物架 | 矩形布尔挖空做层板 | — |

**经验**：布尔是"最后一次操作"。一旦布尔完还要大改，不如退回多边形重做——布尔后的拓扑很难继续编辑。

---

## 技法四：编辑多边形（有机造型）

**核心原理**：球体/长方体只是起点。转「可编辑多边形」后用**挤出、插入、桥接、软选择**逐层塑形，配合「TurboSmooth / 网格平滑」得到圆润表面。

| 作品 | 起手形状 | 塑形手法 |
|---|---|---|
| `apple` 苹果 | 球体 | 顶/底极点收拢出果蒂果脐；中段缩放 + 软选择做不对称鼓形 |
| `bathtub` 浴缸 | 椭圆/球体 | 逐层挤出内腔，内外壁桥接出 40–60 mm 壁厚 |
| `football` 足球 | 球体 | 按经纬线规划五/六边形分区，考验布线耐心 |
| `clay-pot` 陶罐 | 回转体 | FFD 把口沿外翻、腹部微鼓，只动中段控制点 |

**为什么强调"布线"**：平滑后的效果好坏，八成取决于布线是否均匀。极点（三条以上边相交的顶点）附近最容易起皱。

---

## 技法五：FFD 自由形变

**核心原理**：把对象包进一个晶格，拖控制点做整体形变。**只动中段、不动边缘**是做软包和有机形的通用技巧。

- `pillow` 枕头：FFD 2×2×2，四角控制点内收，中间控制点外推 → 自然的塌陷感
- `drawer-unit` 抽屉：FFD 用了 38 处，主要用于柜体边缘的微调
- `clay-pot` 陶罐：口沿外翻

**注意**：FFD 是修改器，堆栈顺序决定结果。放在「平滑」之前和之后完全是两种效果。

---

## 技法六：材质与贴图

**核心原理**：材质 = 着色模型（漫反射/反射/折射）+ 贴图 + 坐标。贴图能不能贴对，取决于 UVW 映射方式选得对不对。

| 作品 | 材质 | 映射方式 |
|---|---|---|
| `clay-pot` 陶罐 | 漫反射贴图（纹理图案.jpg） | 柱状 UVW，接缝藏在背面 |
| `vessels` 器皿 | 金属反射（金属.jpg） | 球面/收缩包裹 |
| `interior-scene` 场景 | 多维子材质分区：木纹 / 砖 / 布 / 金属 | 按材质 ID 分区，先在面级别指定 ID |
| `wall-panel` 墙面 | 材质试验（原贴图 fir2.tga 已丢失） | — |

**多维子材质**是本学期最实用的一招：一个对象、多套材质，靠材质 ID 切换。做室内场景时，墙/地/家具合成一个对象再分区赋材质，比拆成几十个对象好管理。

---

## 技法七：场景合成

`interior-scene`、`layout-wood`、`layout-orange` 三件是"把单件拼起来"的练习。难点不在建模，在**统一**：

1. **单位统一**：全部毫米，否则家具比例全乱；
2. **坐标对齐**：用「对齐」工具按最小/中心/轴心对齐，而不是目测拖；
3. **贴图统筹**：一个场景十几张贴图，路径必须收进同一目录，否则换机器就全丢——这也是本仓库每件作品带 `textures/` 的原因。
