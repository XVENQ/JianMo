原始目录 `3d建模/` 共 **1.7 GB**，含 58 个 `.max`、1071 个素材文件、21 段录屏。仓库只收 43 个 `.max`（33 MB）。**没进仓库的东西，每一条都有理由**——这份文档就是那些理由。

排除分四类：版权与体量、非本人产出、重复覆盖、练习量不足。

## 二、非建模产出：中间文件与归档包

### 4. 8 个 `.zip`（约 9 MB）—— Max 归档包

`4.10/布局.zip`、`4.10/楼梯.zip`、`4.10/毛玻璃.zip`、`4.10/陶罐-1.zip`、`4.13/器皿-1.zip`、`4.13/布局.zip`、`4.14/场景2.zip`、`4.15/场景2.zip`

这些是 3ds Max 的「归档（Archive）」产物：一个 zip 里打包了 `.max` + `MAXFILES.TXT` 资源清单 + 所有外部贴图（按原始绝对路径建目录）。

**处置**：不入库，但做了两件事：
1. 从里面**解出被引用的贴图**，放进对应作品的 `textures/`；
2. 把 `MAXFILES.TXT` 保留为 `_resources.txt`——它记录了原始贴图的完整路径，是重链贴图的依据。

**为什么不直接存 zip**：zip 在 Git 里是不可 diff 的二进制，且与 `works/<作品>/` 里的解密内容重复。资源清单 + 贴图已经能完整还原依赖。

### 5. `4.10/布料/`（4 张 JPG）

与 `素材/布料/` 内容重复（PIC001 / PIC011 / PIC043 / PIC051）。

**处置**：排除。被场景用到的 PIC001 / PIC011 / PIC051 已从 `4.15/场景2.zip` 解到 `works/interior-scene/textures/`。

## 三、重复与覆盖：同题材只留一版

| 排除 | 保留 | 判断依据 |
|---|---|---|
| `4.10/楼梯.max`（704 KB） | `4.10/楼梯/楼梯.max`（888 KB） | 同一跑楼梯的两个版本；目录版经过重新保存，附带完整贴图归档（`C-A-015.jpg` + `MAXFILES.TXT`），依赖更完整 |
| `3.25/吊灯2.max`（592 KB） | `3.25/吊灯.max`（1.2 MB） | 同批次同题材，后者是完整版（8 次布尔 + 球体阵列 + 水晶挂件） |
| `3.11/花架1.max`（660 KB） | `3.11/花架.max`（656 KB） | 同一天两个版本，前者是中间稿；保留的版本含布尔与贴图痕迹 |
| `沙发.max`（根目录，584 KB） | `3.23/沙发.max`（604 KB） | 根目录那份是散落出来的副本，与 3.23 课上的版本同源；按"一作品一目录"保留带日期的版本，便于追溯课堂进度 |

**原则**：同题材多版本时，留**依赖更完整、技法更集中**的那一版；被替代的版本不删原始文件，只是不进仓库。

## 四、练习量不足：入门练习不构成作品

3 月 10 日那一批（项目 1「3Dmax 软件介绍」的第二课作业）共 5 件，全部排除：

| 文件 | 内容 | 排除理由 |
|---|---|---|
| `3.10/扇骨.max` | 阵列做出扇面骨架 | 纯阵列演示，无造型设计 |
| `3.10/手链.max` | 球体 + 阵列串成环 | 同上 |
| `3.10/茶壶放在正方体上方.max` | 茶壶 + 方块 + 对齐 | **文件名即作业说明**，是最基础的对齐练习 |
| `3.10/楼梯.max` | 楼梯基本体拼装 | 同题材在 `4.10` 有完整迭代版（含材质），见上表 |
| `3.10/扶手楼梯.max` | 楼梯 + 圆柱扶手 | 同上 |

其余单点练习：

| 文件 | 内容 | 排除理由 |
|---|---|---|
| `3.11/圆环.max` | 圆环基本体 | 基本体参数练习 |
| `3.17/倒角.max`、`3.17/倒角2.max` | 倒角剖面试验 | 技术试验稿，没有形成完整造型；同批的 `踢脚线`、`商标` 已承载倒角/图形合并技法 |
| `3.18/多面体.max` | 扩展基本体组合 | 基本体练习 |
| `3.23/茶壶的晶格.max` | 茶壶 + 晶格修改器 | 单个修改器演示 |
| `4.14/建模1.max` | 无明确主题 | 命名即"建模1"，与同批 `场景2` 相比是中间稿；`场景2` 已入库 |

**判断标准**：一件东西要进作品集，至少要满足其中一条——
1. 有完整可辨识的造型（不是零件）；
2. 集中演示一种可迁移的技法（布线、布尔、放样、材质）；
3. 是某个场景的组成部分。

只有"会用了"而没有"做出来了"的练习，进 archive 也是噪声。
