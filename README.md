# 3ds Max 三维建模作品集

> 郑州铁路职业技术学院 · 计算机网络技术（可视化技术方向）· 2025 级
> 课程：《三维制作技术》（2025-2026 学年第二学期，72 学时 / 4.5 学分）
> 工具：3ds Max 2022（简体中文）· 系统单位：毫米

本仓库把一学期 46 个课堂练习与作业 `.max` 文件，整理成 **13 件精选作品 + 26 件技法归档**，每件保留 3ds Max 原生场景文件与配套贴图，可直接用 3ds Max 2022 打开。

整理原则不是"全都放上来"，而是**让每一件出现都有理由**：覆盖一种建模手法，或补齐一条技术链路。因此有 7 个文件夹、约 1.5 GB 的素材被明确排除，理由写在 [`docs/排除说明.md`](docs/排除说明.md)。

## 一、技术覆盖

一学期走完 3ds Max 的建模主干：**二维图形 → 三维基本体 → 复合对象 → 多边形建模 → 材质贴图 → 场景合成**。

| 技法 | 代表作品 | 说明 |
|---|---|---|
| 二维样条线 / 放样 / 扫描 | `skirting-line` `vessels` `banana` `icecream-cone` | 截面 + 路径生成连续曲面，缩放变形曲线控制轮廓 |
| 三维基本体与切角 | `sofa` `console-cabinet` `lounge-chair` | 切角长方体拼装软体与板式家具 |
| 阵列与旋转复制 | `staircase-concrete` `spiral-staircase` `crystal-chandelier` | 增量/总计两种阵列模式做重复结构 |
| 布尔运算 | `crystal-chandelier` `washbasin` `wall-shelf` | 差集开孔、镂空骨架，注意运算前统一分段 |
| 图形合并 + 挤出 | `logo-fruit` `relief-text` | 矢量图形投到表面做浮雕标识 |
| 编辑多边形（有机） | `apple` `bathtub` `football` | 球体/长方体转多边形后逐级挤出、软选择塑形 |
| FFD 自由形变 | `clay-pot` `pillow` `drawer-unit` | 只动中段控制点做自然鼓包，避免整块变形 |
| 材质与贴图 | `clay-pot` `vessels` `interior-scene` | 漫反射 / 金属反射 / 多维子材质分区 |
| 场景合成 | `interior-scene` `layout-wood` `layout-orange` | 统一毫米单位后拼装多件单体 |

## 二、目录结构

```
3dsmax-portfolio/
├─ README.md                  本文件
├─ index.html                 可视化索引（可直接用浏览器打开）
├─ works/                     13 件精选作品：.max + textures + preview + 单件 README
│  ├─ staircase-concrete/
│  │  ├─ staircase.max
│  │  ├─ textures/            该作品引用的贴图（保持原文件名）
│  │  ├─ preview/             渲染图（运行 scripts/render_previews.ms 生成）
│  │  ├─ _resources.txt       原始 Max 资源依赖清单
│  │  └─ README.md            建模思路 / 技术要点 / 改进方向
│  └─ …
├─ archive/                   26 件技法归档：仅 .max + _source.txt
├─ docs/
│  ├─ 作品清单.md             全部 39 件的索引表
│  ├─ 技法说明.md             技法递进地图与逐件拆解
│  ├─ 排除说明.md             排除了什么、为什么
│  └─ 源文件映射.md           原始路径 → 仓库路径对照（可追溯）
├─ scripts/
│  ├─ render_previews.ms      批量渲染预览图（MaxScript）
│  └─ relink_textures.ms      批量重链缺失贴图（MaxScript）
├─ .gitattributes             二进制文件标记
├─ .gitignore
└─ LICENSE                    CC BY-NC 4.0
```

**为什么这样组织**：一件作品的所有依赖（场景 + 贴图 + 说明 + 预览）都收在同一个目录里。克隆下来不需要任何额外配置就能逐件打开，也便于按作品回滚、按作品对比版本。`docs/源文件映射.md` 保留了到原始课程文件夹的完整映射，原始资料一旦丢失也能凭它回溯。

## 四、怎么用

### 打开作品

1. 用 **3ds Max 2022** 打开 `works/<作品>/<作品>.max`（2019 及以上版本可打开）；
2. 若提示**贴图缺失**，运行 `scripts/relink_textures.ms`，或在 `Shift+T` 资源跟踪里把缺失项指到同级 `textures/`；
3. 更稳妥的做法：把作品目录设为 Max 项目文件夹（`文件 → 项目管理器`），贴图按相对路径自动定位。

> 原始 `.max` 里的贴图指向的是 `C:\Users\Administrator\Desktop\…` 这类课程机房路径，换机器必然缺失。这是原始素材的客观状态，不是整理造成的——仓库用"贴图同名 + 就近目录 + 重链脚本"三件套解决它。

### 生成预览图

在 3ds Max 里 `脚本 → 运行脚本` 选择 `scripts/render_previews.ms`，脚本会：

- 遍历 `works/` 下所有 `.max`；
- 自动按场景包围盒计算相机位置、布一盏主光 + 一盏补光、加灰色背景；
- 渲染 1200×1200 PNG 到各作品的 `preview/` 目录；
- 输出一份渲染日志。

默认用扫描线渲染器（不需要额外配置），也可在脚本头部改成 Arnold / V-Ray。

## 五、版本管理约定

| 约定 | 原因 |
|---|---|
| `*.max` 在 `.gitattributes` 里标记为 `binary` | 避免 Git 把二进制当文本做行尾转换而损坏文件 |
| 一作品一目录 | 按目录回滚、按目录对比，比"一堆散文件"更好管理 |
| 贴图保持原文件名 | 重命名会让 `.max` 内部引用失效，必须靠重链脚本补救 |
| 不提交 `素材/`、`教程/` | 1.5 GB 教材配套资源与教师录屏，非本人产出，也不适合版本库（见排除说明） |
| 单个 `.max` < 3 MB | 未触发 GitHub 单文件限制，暂不需要 Git LFS；后续若加高模再启用 |
